# 19 November 2026, in one picture

An entry for make.fun's *Sum up 19 November's world news in one image* bounty.

The repository holds `entry.png`, a 1024x1024 editorial summary of the day's
world news, and `main.py`, the program the grader runs: it copies that image to
`/output/entry.png` and prints its size. Standard library only, no network, and
two runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```

## The image

Front-page grid, in the order a picture editor would give the day: the EU's
EUR 45bn loan for Kyiv and the Berlin talks, Iran's claim to have downed a US
drone with two American carriers in the Arabian Sea, Xi at the APEC summit and
Indonesia's rate rise to 6% for the rupiah, paramilitary units out in Dhaka
during the Hasina unrest, the deadlock at COP31, and Ronaldo's record with
England entering the World Cup fray. The date runs across the masthead and the
footer, so the picture names the day it sums up.
